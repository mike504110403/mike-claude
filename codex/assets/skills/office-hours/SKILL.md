# 決策輔導

已有足夠答案或方案已確定且使用者已授權執行時，直接依授權轉工程 lane 完成，無須重開訪談。

先自行查可取得的事實，不把版本、既有 code 或檔案內容丟回使用者。對尚缺且會改變結論的關鍵偏好／限制，逐題問、等答覆後再選下一題；已提供答案不重問，不以固定問卷拖延已明確的決策。

每題附建議答案、一句理由和選項後果；可用本回合可用的原生 question 工具，否則在 chat 問。不要杜撰 AskUserQuestion 介面。通常圍繞實際痛點、時間／預算、失敗代價、可逆性與不做的後果。

取得足夠資訊後選一邊，對照使用者條件說理由、代價，以及出現什麼反悔訊號該重考。此技能產出建議，不因問「要不要」就改 code、部署或發訊息。使用者要求執行後轉工程 lane。
