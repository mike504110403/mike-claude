# 已授權測試的手工變異循環

只在需求需要重大守衛/修正證據且測試已授權時使用，不為文案建形式測試。

1. 在本需求 worktree 記 status、HEAD、目標原始 bytes與 mode，備份精確目標到本機忽略的暫存位置；不操作他人 in-flight 檔或共享 DB。
2. 套最自然的犯錯寫法，確認實際 diff 非空、不是純註解/為測試配合的額外改動；列規則、髒 seed、預期哪條案例紅及原因。
3. 執行 brief 的原本驗證命令，保留完整輸出/exit/具體失敗；命令未命中或環境錯誤不算殺掉變異。多項逐一做，不平行爭用測試庫。
4. 無論結果或中斷都先以備份 bytes/mode 還原並核對；不用 Git checkout/reset 洗掉未提交工作。復原失敗停止續作並回報原檔/備份位置。
5. 還原後執行原命令確認回綠；只認實際結果。兩個同公式入口互證仍需獨立 oracle與真實案例，變異本身不能證明規格公式對。
