Mike 有 GitKraken Pro，2026-07-21 評估過 GitKraken CLI（`gk`）與其 MCP server 後決定不採用。

**Why:** 目前工作都是單 repo（`dev` 切 feature branch、地端 merge），gk 的核心賣點是跨 repo work item 與 workspace 管理，用不上；AI commit/PR 功能與大腦既有能力重疊。

**How to apply:** 不要主動推薦接 GitKraken MCP。若未來出現多 repo / 跨服務需要同步管理的情境，可以重新提起。
